# SmartishNight
Electronics for a ESP32/NeoPixel based nightlight

| pin | output    |
|-----|-----------|
| 4   | Button    |
| 15  | IR        |
| 25  | Data out  |
| 32  | LED power |

## Enclosure

A parametric 3D printable case for the board lives in
[`enclosure/`](enclosure/): two parts that clip together, cable strain relief,
and no support material. There are three versions - USB-C port exposed,
hardwired power with a cable clamp, and a gasketed outdoor one.
